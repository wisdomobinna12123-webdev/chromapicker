# Chroma Picker 🎨

A simple, fast, and beautiful UI color picking tool built from scratch with HTML, CSS, and JavaScript.  
Pick, copy, and generate color palettes for your websites and apps in seconds.



## ✨ Features
- **Color Picker** - Click anywhere on the canvas or use the color wheel to pick colors
- **Hex, RGB, HSL Copy** - One-click copy for all color formats
- **Palette Generator** - Generate complementary, analogous, triadic, and monochromatic palettes
- **Shade & Tint** - Instantly create lighter and darker variations of any color
- **Color Contrast Checker** - Check WCAG AA/AAA contrast for text and background
- **Save Favorites** - Store your favorite colors in localStorage
- **Dark/Light Mode** - Auto themes with `prefers-color-scheme`
- **Responsive** - Works great on desktop, tablet, and mobile
- **No Dependencies** - 100% Vanilla JS
